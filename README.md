# Machine Learning Operations (MLOps) Assignments & Projects

A comprehensive collection of practical MLOps assignments covering end-to-end machine learning lifecycle workflows, including dataset versioning, experiment tracking, pipeline preprocessing, workflow orchestration, API serving, containerization, CI/CD automation, monitoring, and cloud deployment.

---

## 📁 Repository Structure

| Directory | Topic / Technology | Description |
|-----------|--------------------|-------------|
| **`Ass_1`** | **Dataset Versioning** (DVC & Git) | Versioning datasets, tracking data changes across iterations, and managing remote storage. |
| **`Ass_2`** | **Experiment Tracking** (MLflow) | Logging parameters, metrics, artifacts, and model tracking using MLflow. |
| **`Ass_3`** | **Preprocessing Pipeline** | Modular, reproducible data preprocessing and feature transformation pipelines. |
| **`Ass_4`** | **Workflow Orchestration** (Apache Airflow) | DAG workflows for scheduling, automating, and monitoring ML tasks. |
| **`Containerizing a Machine Learning Model using Docker`** | **Containerization** (Docker) | Packaging trained ML models into lightweight, portable Docker containers. |
| **`Create REST API Using FAST API`** | **Model Serving** (FastAPI) | Exposing machine learning inference via RESTful APIs with input validation and testing. |
| **`Implement CICD Pipeline Using GitHub Actions`** | **CI/CD Automation** (GitHub Actions) | Automated testing, linting, building, and continuous delivery pipelines. |
| **`Monitor a Machine Learning Model Using Prometheus and Grafana`** | **Monitoring & Observability** (Prometheus & Grafana) | Tracking real-time inference latency, throughput, error rates, and custom model metrics. |
| **`Train and Deploy a Machine Learning Model using AWS`** | **Cloud ML Deployment** (AWS) | Model training, artifact packaging, and cloud deployment on AWS infrastructure. |
| **`New folder`** | **Assignment Documentation** | Complete documentation reports (`MLOA_01.docx` to `MLOA_09.docx`). |

---

## 🛠️ Tech Stack & Tools

- **Version Control & CI/CD**: Git, GitHub Actions, DVC
- **Tracking & Orchestration**: MLflow, Apache Airflow
- **Serving & Frameworks**: FastAPI, Python, Scikit-Learn
- **Containerization & Observability**: Docker, Docker Compose, Prometheus, Grafana
- **Cloud Infrastructure**: Amazon Web Services (AWS)
